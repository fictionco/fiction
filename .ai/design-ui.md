# Design & UI Rules

## Core Design Philosophy

- Follow tufte principles. Maximize data-ink ratio.
- Follow **first principles**: eye-tracking patterns, reading flow, visual hierarchy, minimal cognitive load.
- Editorial minimalism. Small text should be mono-font. Rely on visual hierarchy and contrast, not font weight or size.
- Optimize readability. Use line length, line height, and vertical rhythm to optimize readability.

## Layout Heuristics

- Text Formatting
  - Optimize line length for readability.
  - Make content responsive, and break up long paragraphs.
  - Optimize line breaks and alignment based on device. Use pretty line breaks.
- Max 200 words per page
- Eye Tracking
  - Longer line lengths needs taller line heights.
  - Don't make users jump around from left to right.
  - Use grid systems to support scanning, establish relationships between content.
  - Optimize line height for readability.
- Visual Separation and Hierarchy
  - Use white space to separate content.
  - After white space, use borders to balance content and show boundaries.
  - Use visual rhythm to guide user attention.
  - Use media to support content, not to distract
- Keep images, media and figures proportional to their emphasis. Often a popup can be called rather than video shown inline.

## Conversion & Sales Psychology Principles

- Clarity and specificity: Don't write to impress or amuse — write to sell.
- Use content framing to build **momentum** — each section should build toward action.
- Don't use better, faster, best, or other superlatives. Use specific numbers and data.
